223/224 (room1_) and 225 (room2_). Their authored hide/show ranges include
terrain and props. L5A3_G was outside the co-op section router, so a leading
player's room transition could hide the stationary player's floor. Route these
two exact groups through the existing per-player section ownership and collision
contact path. The shared world still unloads a room once neither player needs it.
Unrelated scripts and visibility groups keep retail behavior.

obstruction ray from that camera toward its tripod, remembers up to eight
blocking items in the camera's own list, and marks their render flag 0x800.

stage (455839-45588B) and another authored boss path (488778-4887C9).
P2's separate native camera tick already contains the obstruction logic but
did not receive the boss script's enable flag. In USER boss camera mode, mirror
P1's field_F9 onto P2 before its native camera tick, so P2 chooses blockers
from its own position. Diagnostics report both flags for manual verification.
The original game uses shared item render bits, so the visual result and any
cross-view interaction still require a P1/P2 gameplay check.

CPLAYER-21-TERRAIN - 2026-09-18
Implemented and deployed; live bank crossing verification pending.

Evidence from CPLAYER-20 run: at t=1051631562, ticks=7717, P1=-4388,-96,3129
and P2=-7569,-96,-1698, unowned section command count increased from 0 to 5.
Letterbox became 30; hidden item count increased 29->58, with unchanged 301
items and resource/grid hashes. Existing Command(owner=0) cleared BOTH player
bits. Thus a shared script could discard previously protected terrain.

Native 4DE8D0 sets command-point byte+4 on touch but tests shared byte+5 before
enqueue. A second player is suppressed while that latch remains set, even on
later frames. Recording ownership alone does not execute any visibility changes
when no command is enqueued. Native reset/release is 4DE890/4DE8B0.

Fix: global terrain visibility commands preserve participant masks; their hides
apply only if neither player needs the item. Collision contact also projects
leading BF section commands directly into the contacting player's requirements,
independent of the shared latch. Decoder is bounded by the next node address and
stops before other opcodes/unrelated names. Does not replay command lists or links.
Original shared trigger invocation and fall interception remain intact.

The named terrain resolver at 4E6A40/4C9230 was compared with our name/range/CRC
resolver; no discrepancy found. Tests now consume actual L1A3 nodes including
67/70 (five-command visibility batches), 68 and 71, and compile the production
collision wrapper with a latched native-call fixture. Both role directions and
release after both players leave pass. Other co-op suites and validators passed.

Known scope: audited bank terrain groups only, not arbitrary script-controlled
puzzle geometry or actual resource streaming across other levels. Exact screenshot
location still requires user gameplay retest. Game not launched by agent.
